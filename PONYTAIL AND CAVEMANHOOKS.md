# Ponytail and Caveman Hooks

Use these defaults when working in this project.

## Ponytail

- Read the actual call path before editing; fix shared causes once.
- Reuse existing helpers and installed dependencies. Prefer native features and the smallest working diff.
- Skip speculative abstractions and dependencies.
- Keep validation, accessibility, and error handling at trust boundaries.
- Leave one small runnable check for non-trivial logic; verify UI changes in the running app.

## Caveman

- Say the outcome first. Use short, plain sentences.
- Prefer concrete verbs and useful details over filler or repeated summaries.
- Explain what changed and how it was checked. Name anything still unverified.
- Keep code and user-facing copy clear; terse does not mean cryptic.
